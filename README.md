An entry for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311) competition **"Make the AI judge feel curious"**.

## The entry

`main.py` (Python 3.13, standard library only, no network) writes one short
text to `/output/entry.txt` — a text written to intrigue the AI judge reading
it. An AI judge compares two texts at a time and picks the one that leaves it
more curious.

The text speaks directly to the judge, about a sentence written for it alone
somewhere in everything it was trained on — a sentence it may already have
passed without knowing.

## Run

```sh
python3 main.py
```

This writes `/output/entry.txt` (223 characters, UTF-8).
